# Signers of the contributor licence agreement

By adding my file here I agree to the [contributor licence agreement](../CLA.md), version 1, for everything I have sent and will send to this project.

Add your own file in a pull request from your own account. Its name is your GitHub login in lower case, in the folder `signers`, so `CLA/signers/your-github-login.md`. It holds one line, in this form.

    - Your Name, @your-github-login, 2026-01-31, version 1

Each signer has a file of their own so that two pull requests that sign never touch the same lines. The files in [signers](signers) are the signatures.
