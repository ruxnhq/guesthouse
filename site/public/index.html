Features

Everything a GPU does, in a virtual machine.

Give it an ISO and Guesthouse installs Windows or Ubuntu by itself, with the GPU set up. No terminal needed.

Windows on NVIDIA

Direct3D 12 and 11, Vulkan, OpenGL, OpenCL, CUDA, NVENC and NVDEC all run on the real card, and Edge is hardware accelerated.

Windows on AMD Experimental

AMD's own Windows driver, from AMD's installer. The desktop, Direct3D 12 and 11, Vulkan and OpenGL work, from RDNA2 to RDNA4.

Linux guests

NVIDIA's Linux driver in the guest, its calls forwarded to the host's: CUDA, Vulkan, NVENC and NVDEC at about host speed. On AMD, Mesa on the real card.

Windows hosts too Preview

On Windows 11, Home or Pro, through Virtual Machine Platform. No Hyper-V needed. Windows and Ubuntu guests share your card the same way, on NVIDIA and AMD, and on Intel Arc as an experiment.

Drag files in and out

On Linux, drop files on the viewer and they land where you let go in Windows. Drag them off the picture to bring them back as a copy.

With or without a desktop

The app for a window, guesthouse-vm for a terminal or a PC with no screen, or beside your own QEMU and libvirt.

Copy, throw away, move Linux

Duplicate a machine in a second. Run a throwaway that forgets everything when it stops. Export one to a file and import it on another PC.

Ready-made machines Linux

Pick a recipe and the machine comes set up, with Steam on Windows or the CUDA toolkit on Ubuntu. Windows can be installed lean, without the apps you'd never open in a VM.

See who has the card Linux

The library shows how the card is shared between your running machines, and a machine can save a snapshot by itself before a risky change.

How it works

Hyper-V's GPU protocol, taught to KVM.

Hyper-V has a way to share a GPU, called GPU-PV: the guest runs the vendor's normal driver on the host's card. It's how WSL gets its GPU. Guesthouse speaks it on Linux, so Windows boots, finds what looks like a Hyper-V GPU, and loads the vendor's driver. On Windows, it uses Windows' own.

  • The guest's commands aren't translated: its driver writes them, and the card runs them.
  • Each program in a guest gets its own GPU page tables, and can't read another's memory.
  • On Linux, QEMU and the daemon are jailed with Landlock and seccomp, and the daemon checks everything a guest sends.
